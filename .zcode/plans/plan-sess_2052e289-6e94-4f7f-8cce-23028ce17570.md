# 按 miuix 标准重构顶栏 + 悬浮底栏

## Context

对照 miuix 0.9.5-beta03 官方 demo/源码（`GlassTopAppBarDemo` / `GlassNavigationBarDemo`）发现当前应用的差距：

**顶栏**：`GlassTopAppBar` 在 11 处重复粘贴相同的高级材质判断（bandBrush/fill 三元式）；都没传 `backdrop`，按钮只是平色填充；且 miuix Scaffold 本身把内容放在 (0,0) 与顶栏重叠渲染，而当前所有页面用 `padding(padding)` 把内容推到栏下方 —— band 渐变无内容可压暗，玻璃效果形同虚设。

**底栏**：三个效果（NONE/FROSTED_GLASS/LIQUID_GLASS）材质搭配基本正确，但自定义配色覆盖了 miuix 动态取色感知的默认配色，NONE 缺少标准 Float 阴影，items 每次重组重建，宽度为固定 236dp 胶囊（用户已选 miuix demo 全宽样式）。

**用户决策**：① 完整 miuix 标准（内容滚动穿透玻璃顶栏）；② 底栏改 fillMaxWidth + 16dp 边距；③ 底栏用 miuix 默认配色。

## 实施步骤

### 1. 新建共享顶栏组件 `ui/components/topbar/AppGlassTopAppBar.kt`

集中重复的高级材质逻辑（现状见 `BaseScreen.kt:597-605`、`SheetComponents.kt:70-78`）：

```kotlin
@Composable
fun AppGlassTopAppBar(
    title: String,
    onBack: (() -> Unit)? = null,          // null 时不渲染返回键
    actions: @Composable RowScope.() -> Unit = {},
    backdrop: Backdrop? = null,            // 仅 advancedMaterial=true 时透传
    modifier: Modifier = Modifier,
)
```

- `bandBrush = if (advanced) GlassTopAppBarDefaults.bandBrush(surface) else SolidColor(surface)`
- `fill = if (advanced) GlassTopAppBarDefaults.buttonFill() else Color.Transparent`
- `backdrop = if (advanced) backdrop else null`（平材质时不采样）
- `onBack != null` 时渲染标准返回键：`GlassIconButton` + `MiuixIcons.Glass.ChevronBackward` 24dp "返回"
- 保持 `expandable = false`（与现状一致，不做大标题折叠，避免逐页接 ScrollBehavior）

### 2. 升级 `ui/components/SheetComponents.kt` 的 `MiuixSubScreen`（覆盖 10 个子页面）

按官方 demo 模式接入背板，新增 `actions` 参数：

```kotlin
val advanced = AppRepository.getAdvancedMaterial(context)
val backdrop = if (advanced && isRuntimeShaderSupported()) rememberLayerBackdrop {
    drawRect(MiuixTheme.colorScheme.surface); drawContent()
} else null
MiuixScaffold(topBar = { AppGlassTopAppBar(title, onBack, actions, backdrop) }) { padding ->
    Box(Modifier.fillMaxSize().then(if (backdrop != null) Modifier.layerBackdrop(backdrop) else Modifier)) {
        content(padding)
    }
}
```

### 3. 重构 `BaseScreen.kt` 的 `MainScaffold`

- 背板创建条件扩大：`isFloating && navEffect != NONE` → `(isFloating && navEffect != NONE) || (advancedMaterial && glassSupported)`（顶栏玻璃按钮与底栏共用同一背板）
- topBar 换用 `AppGlassTopAppBar(title = currentDestination.label, actions = { 搜索、设置 }, backdrop)`
- 内容区按 demo 模式重排（`BaseScreen.kt:646-698`）：外层 Box 只保留 `padding(start/end/bottom)`，**top 不再消费**；给三个页面新增 `contentTopPadding: Dp = padding.calculateTopPadding()` 参数
- 页面适配（`contentTopPadding` 默认 0，非主入口不受影响）：
  - `HomeScreen.kt:431`：常驻筛选头的 Column 加 `padding(top = contentTopPadding)`（头部保持常驻设计，仅下移避开栏区）
  - `DiscoverScreen.kt:329`：滚动 Column 首位插入 `Spacer(Modifier.height(contentTopPadding))` → 内容真正滚动穿透顶栏
  - `MineScreen.kt:325`：LazyColumn `contentPadding` 增加 `top = contentTopPadding` → 同上

### 4. 优化 `ui/components/navbar/GlassBottomBar.kt` 三效果

- **布局**：删掉 `BarItemWidth` 固定宽度，改 miuix demo 标准 `padding(bottom = BarBottomMargin).fillMaxWidth().padding(horizontal = 16.dp)`（新增 `BarHorizontalMargin = 16.dp`）
- **配色**：删除 `indicatorColor / indicatorPressedColor / selectedColor / unselectedColor` 四个自定义参数 → 组件默认（动态取色开启时选中色为 primary，否则 onBackground；未选中 onBackground；指示器用默认色）
- **NONE 效果**：`shadow` 由 `null` 改为 `GlassShadows.Float`（miuix 默认悬浮阴影；材质仍回退 surfaceContainer 胶囊）
- **FROSTED_GLASS / LIQUID_GLASS**：材质搭配已是标准（CommonMediumRegular+puredThinGlass / BionicMediumRegular+popupViewGlass+BigLight/BigDark+High），保持不变
- **items 稳定化**：`remember(entries)` 包裹 `GlassNavigationItem` 列表（官方文档要求实例稳定）
- `FloatingBarContentHeight` 常量与 60dp 高度保持不变（设置页的底栏选项 UI 无需改动）

### 5. 各页面顶栏替换 + 穿透适配

**自带 Scaffold 的 9 个页面**（删除重复的 GlassTopAppBar 块，换 `AppGlassTopAppBar`；各自建 backdrop + 内容根加 `layerBackdrop`；滚动容器把 `padding.calculateTopPadding()` 挪进 contentPadding，非滚动页保持原布局）：
- `mine/SettingsScreen.kt`、`mine/WatchHistoryScreen.kt`、`mine/LocalVideosScreen.kt`、`mine/AboutMeScreen.kt`、`mine/SponsorScreen.kt`
- `discover/BoxOfficeRealtimeScreen.kt`、`discover/InviteMasterScreen.kt`、`discover/MediaAnalyzeResultScreen.kt`、`discover/ScrollingTextScreen.kt`

**MiuixSubScreen 的 10 个消费方**（只需把 `.padding(padding)` 改为 start/end/bottom + 滚动容器 contentPadding top）：
- `discover/AnimeRankScreen.kt`、`HotNewsRankScreen.kt`、`BoxOfficeTotalScreen.kt`、`MovieWorldScreen.kt`、`MovieRatingScreen.kt`、`ProfileAvatarScreen.kt`、`MediaAnalyzeScreen.kt`、`TvLiveScreen.kt`、`mine/CacheManageScreen.kt`、`about/LicenseScreen.kt`

**不动**：`MovieSearchScreen` / `MovieDetailScreen`（搜索条/播放器自有结构）、`ImageViewerScreen`。

## 验证

1. `./gradlew :app:assembleDebug` 编译通过（Windows 下 `gradlew.bat`）
2. 手动检查点（真机/模拟器 Android 13+）：
   - 主页三个 tab：Discover/我的 列表滚动时内容穿过玻璃顶栏、band 渐变压暗、右上角按钮实时玻璃折射
   - 观看历史/设置等子页面：同上 + 返回键正常
   - 设置页切换「高级材质」关闭 → 顶栏回退平材质、按钮平色
   - 设置页依次切换底栏三效果：标准（新阴影）/ 轻透磨砂 / 柔光玻璃，底栏全宽 + 默认配色
   - 停靠式底栏（悬浮关闭）不受影响；Android 13 以下自动降级无崩溃
